Este panel publica cambios directo en el repositorio (blog, galería y estado de encargos) usando la API de GitHub. Se autentica con un Personal Access Token: el token se guarda solo en el localStorage de este navegador y viaja únicamente hacia api.github.com.

Seguridad: usa un token con el mínimo permiso posible (fine-grained con Contents: Read and write solo de este repo, o clásico con scope repo). Si usas una computadora prestada, activa el navegador privado y cierra la sesión al terminar.

¿Sin token? Crea uno aquí: token clásico (scope repo) ↗ · token fine-grained (Contents: write) ↗
